# Product images

All 60 images in this folder are original illustrations drawn for this project (one per product
base type, shared by every variant). They contain no third-party photos, logos or text.

- Source: `frontend/scripts/product-art.mjs` (SVG drawing code)
- Render: `node scripts/build-product-images.mjs` writes 600 x 600 WebP files here
