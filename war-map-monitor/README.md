# 🇺🇦 Avrora War Map Situational Intelligence & Real-Time Data Sheet System

> **Система оперативного табелю загроз для 1,935 офіційних активних магазинів «Аврора» в Україні.**

The dashboard reports source provenance explicitly: official alerts.in.ua provides oblast and hromada coverage when a token is configured; the public fallback is oblast-only; offline simulation is clearly labelled. Frontline status distinguishes a current feed from stale cache or baked sample data.

Ця система зчитує оперативні геопросторові дані лінії зіткнення (**DeepStateMap**) та сповіщення про повітряні загрози (**Alerts.in.ua**), розраховує дистанції до бойових дій для кожного магазину мережі та автоматично генерує **живий Data Sheet** (табель загроз) у форматах **CSV, Excel та JSON**, оптимізований як для роботи персоналу, так і для інтеграції в **AI-рідери, модулі прогнозування та системи тактичних підказок**.

## 📊 Структура Колонок Data Sheet

Згенерований табель містить вичерпні параметри для кожного магазину:

1. `store_id`: Унікальний номер точки (наприклад, `AVR-0812`)
2. `name`: Офіційна назва магазину
3. `city`: Населений пункт
4. `oblast`, `raion`, `hromada`: Повна адміністративна прив'язка
5. `address`: Фізична адреса
6. `dist_frontline_km`: Точна відстань у км до найближчої лінії зіткнення DeepState
7. `threat_zone`: Код зони (`RED`, `ORANGE`, `YELLOW`, `GREEN`)
8. `alert_status`: Статус повітряної тривоги (`ACTIVE_HROMADA`, `ACTIVE_OBLAST`, `CLEAR`)
9. `risk_score`: Комплексний індекс небезпеки від 0 до 100
10. `store_mode`: Режим роботи (`ШТАТНО`, `ТРИВОГА (В УКРИТТІ)`, `ЗАКРИТО`)
11. `action_uk`: Пряма оперативна вказівка українською мовою для директора магазину
12. `emergency_demand`: Оцінка ажіотажного попиту (`NORMAL`, `ELEVATED`, `HIGH`, `CRITICAL`, `EXTREME`)
13. `shelter_nearby`: Локація та відстань до найближчого бомбосховища
14. `has_generator`, `generator_fuel_l`: Наявність та залишок пального для автономного живлення
15. `manager_name`, `manager_phone`: Контактна особа для екстреного зв'язку
16. `updated_at`: Часова мітка генерації запису

## 🚀 Швидкий Старт

### 1. Перехід до каталогу проекту
```powershell
cd C:\Users\fabijus\.gemini\antigravity\scratch\avrora-war-monitor
```

### 2. Запуск одноразового циклу розрахунку табель-файлів
```powershell
$env:PYTHONIOENCODING = "utf-8"
python monitor.py --once
```
*Це зчитає карту війни, розрахує ризики для всіх магазинів та збереже файли в папку `output/`:*
- `output/avrora_war_threat_sheet.csv` (відкривається у Microsoft Excel з коректним відображенням кирилиці)
- `output/avrora_war_threat_sheet.xlsx` (книга Excel з кольоровими індикаторами та окремим аркушем KPI)
- `output/avrora_war_threat_sheet.json` (повний масив записів для API)
- `output/avrora_threat_summary.json` (зведені показники по всій мережі)

### 3. Запуск живого консольного монітора (безперервний режим)
```powershell
python monitor.py --interval 30
```

### 4. Запуск веб-дашборду та REST API
```powershell
python server.py
```
Відкрийте в браузері:
- **Веб-дашборд**: [http://localhost:8000](http://localhost:8000) (інтерактивна таблиця з автооновленням, фільтрами по зонах, статусах тривог та пошуком)
- **REST API документація (Swagger)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **Пряме завантаження живого CSV**: [http://localhost:8000/api/datasheet/csv](http://localhost:8000/api/datasheet/csv)

## 🤖 Модуль Інтеграції з AI (Reader & Prediction)

Файл `ai/ai_prompts.py` та скрипт `ai/ai_reader_demo.py` реалізують інтерфейс для подальшого підключення до LLM (Gemini 1.5/2.0 Flash та інших).

### Запуск тесту генерації AI-підказок:
```powershell
python ai/ai_reader_demo.py
```

### Доступні AI-моделі взаємодії:
1. **Single Store Advisor (Асистент директора точки)**:
   Приймає один рядок з Data Sheet і генерує персоналізований 3-кроковий чек-лист (дії персоналу, паливний баланс генератора, викладка ліхтариків та павербанків).
2. **Chain Logistics Predictor (Прогнозувальник постачання мережі)**:
   Приймає агреговані дані та формує рекомендації для операційного штабу: ймовірні години простою магазинів у розрізі регіонів та коридори безпечного руху автотранспорту.
